# API选品牌更新

设计日期：2026-09-08。

## 设计方向

图标将字母 A 的上升斜线与勾选符号结合，表达 API 服务的筛选与推荐。使用钴蓝底色、白色主笔画和浅青色勾选，减少小尺寸中的细节。字标保留 API选，去掉微小英文副标题，提升导航栏中的可读性。

中文和俄文文字已转换为矢量轮廓，不依赖访问者电脑或手机上的字体。字体轮廓来源为 Windows Arial Bold 和微软雅黑 Bold；未分发字体文件。

## 交付文件

- `public/logo.svg`：中文横版，204 × 56。
- `public/logo-ru.svg`：俄文横版，204 × 56。
- `public/logo-mark.svg`：独立矢量图标。
- `app/icon.svg`：浏览器矢量图标。
- `app/favicon.ico`：16、32、48、64、256 像素图标。
- `app/apple-icon.png`：180 × 180 像素 Apple 图标。
- `design/brand/logo-transparent.png`：透明背景中文横版，宽 1224 像素。
- `design/brand/mark-512.png`：512 × 512 像素图标。
- `design/brand/logo-preview.png`：完整设计预览及新旧对比。

保持原有资源地址和布局尺寸，现有网站顶部会直接使用新版；手机端仍使用独立图标。2026-09-08 用户已确认设计并授权上线，实际发布状态以 Vercel 生产部署及线上资源核验为准。

## 验证

已检查 SVG 文件有效性、字标轮廓、ICO 各尺寸可解码和 Apple 图标尺寸，并查看完整预览中的中文、俄文及小尺寸效果。本次未修改页面逻辑。

## 重新导出

在仓库根目录执行 `python design/brand/build_logo.py`，再执行 `node design/brand/render_logo.mjs`。前者使用 Windows 系统字体生成字标，后者使用项目已有的 sharp 生成图片和图标。源码和原始标志可通过 Git 历史恢复。
