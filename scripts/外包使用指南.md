# 外包人员使用指南

## 环境准备

### 1. 安装 Node.js

访问 https://nodejs.org/ 下载并安装 **LTS 版本**（推荐 v18 或更新）。

安装完成后，打开终端验证：

```bash
node --version    # 应显示 v18.x.x 或更高
```

### 2. 下载项目代码

**方式一：使用 Git（推荐）**

```bash
git clone <仓库地址>
cd aio-guide
```

**方式二：直接下载 ZIP**

1. 访问仓库页面
2. 点击绿色的 **Code** 按钮
3. 选择 **Download ZIP**
4. 解压到本地任意目录
5. 打开终端，cd 进入解压后的目录

### 3. 无需安装依赖

这两个独立脚本 **不需要运行 `npm install`**，直接用 Node.js 就能跑。

## 日常任务

### 任务一：抓取 AI 快讯（每天一次）

```bash
node scripts/standalone-fetch-ai-news.js
```

**执行时间建议**：每天早上 **9:00**

**输出示例**：
```

  极客公园：命中 2026-08-13，共 20 条
  机器之心：命中 2026-08-13，共 15 条

=== 汇总 35 条快讯 ===

✅ 已导出到 ai-news_2026-08-13_1786615048586.json
   完整路径: /path/to/aio-guide/scripts/exports/ai-news_xxx.json

请将此文件发送给数据接收方。
```

生成的文件在 `scripts/exports/` 目录下，文件名格式：`ai-news_日期_时间戳.json`

## 可选参数

### 快讯脚本

```bash
# 指定日期（默认为今天）
node scripts/standalone-fetch-ai-news.js --date=2026-08-12

# 强制重新抓取，忽略缓存
node scripts/standalone-fetch-ai-news.js --force
```

### 榜单脚本

```bash
# 强制重新抓取，忽略缓存
node scripts/standalone-sync-providers.js --force
```

## 如何发送文件

将 `scripts/exports/` 目录下生成的 JSON 文件发给数据接收方（我）：

- 邮件附件
- 微信/QQ 文件传输
- 云盘分享链接（百度云、阿里云盘等）

**重要**：文件名不要改，导入脚本会从文件名解析日期。

## 常见问题

**Q：scripts/exports/ 目录不存在**  
A：首次运行时脚本会自动创建。

**Q：出现网络错误**  
A：可能是网络波动，等待几分钟后重试。脚本有内置缓存，重复运行不会造成额外请求。

**Q：抓取到 0 条数据**  
A：正常现象。ainav.cn 会在前一天晚上 23:00 左右更新当天内容，早上抓取前一天的数据最稳定。

**Q：需要定期更新代码吗？**  
A：一般不需要。如果我更新了抓取逻辑，会通知你用 `git pull` 更新或重新下载 ZIP。

## 自动化（可选）

如果希望定时自动执行，可以配置系统定时任务：

- **Windows**：任务计划程序
- **Linux/Mac**：cron

示例 cron 配置：
```cron
# 每天早上 9:00 抓取快讯
0 9 * * * cd /path/to/aio-guide && node scripts/standalone-fetch-ai-news.js

# 每周一、四 10:00 抓取榜单
0 10 * * 1,4 cd /path/to/aio-guide && node scripts/standalone-sync-providers.js
```
