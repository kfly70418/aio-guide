## 核心区别

**会员（Subscription）** 和 **API（Application Programming Interface）** 是同一家公司的**两套独立产品**，就像买了视频网站会员不等于获得视频上传权限一样：

- **会员**：面向个人用户，在官方网页或 App 中直接聊天，按月订阅（如 ChatGPT Plus ¥140/月）
- **API**：面向开发者或第三方软件，通过编程接口调用模型，按实际用量计费（如 GPT-4 每百万 Token ¥210）

即使登录的是同一个账号，**会员额度和 API 余额不互通**，分别计费、分别管理。

---

## 一个简单判断方法

不确定自己在用哪个产品？看这两点：

### 你在用会员（Subscription）
- ✅ 直接在官方网站或 App 中输入问题（如 `chat.openai.com`、`claude.ai`）
- ✅ 界面上有"升级到 Plus/Pro"按钮
- ✅ 付款页面显示"每月 $20"或"年付优惠"

### 你在用 API
- ✅ 客户端要求填写 **API Key**、**Base URL**、**模型名称**
- ✅ 在开发者平台（如 `platform.openai.com`）创建密钥
- ✅ 账单按 Token 用量计费，不是固定月费

**常见混淆点**：
- Cherry Studio、Chatbox、Cursor 等第三方客户端虽然界面像聊天软件，但它们调用的是 **API**，不是会员服务
- 客户端本身可能免费，但调用 API 仍会产生费用

## 为什么要分开收费

### 产品定位不同

| 维度 | 会员（Subscription） | API |
|------|-------------------|-----|
| **使用者** | 个人终端用户 | 开发者、第三方软件 |
| **使用场景** | 网页/App 直接聊天 | 客户端、自动化脚本、代码集成 |
| **计费方式** | 固定月费（如 ¥140/月） | 按 Token 用量（如 ¥0.21/千 Token） |
| **额度规则** | 每 3 小时 40-80 条消息 | 按账户余额和速率限制（RPM/TPM） |
| **功能边界** | 包含文件上传、联网、插件、图像生成 | 仅调用模型接口，功能由客户端实现 |
| **账单管理** | 自动续费，取消即停止扣费 | 预付费，用完即停，支持自定义限额 |

### 成本结构不同

**会员**：
- 包含官方界面开发和维护
- 提供文件存储、历史记录、插件生态
- 承担固定的服务器和带宽成本
- 需要人工客服和滥用审核

**API**：
- 仅提供模型调用接口
- 不包含前端界面和文件存储
- 按实际计算量收费，避免资源浪费
- 需要开发者自行实现功能和滥用控制

## 价格对比：哪个更划算？

### ChatGPT Plus 会员 vs GPT-4 API

**会员方案**：
- 月费：¥140（$20）
- 额度：每 3 小时约 40 条消息（GPT-4）
- 按 30 天计算：约 9,600 条消息
- **单条成本**：¥0.015/条

**API 方案**（通过中转站）：
- GPT-4 价格：约 ¥0.21/千 Token（输入输出均价）
- 单次对话（100 Token 输入 + 300 Token 输出）：约 ¥0.084
- ¥140 可用：约 1,667 次对话
- **单条成本**：¥0.084/条

**结论**：
- 如果每天聊天 **超过 50 次**，会员更划算
- 如果每天聊天 **少于 20 次**，API 更划算
- 如果需要 **自定义客户端、自动化脚本**，只能用 API

> ⚠️ **注意**：上述价格基于 2026 年 8 月中转站实测，官方 API 价格约为中转站的 2-3 倍。

### Claude Pro 会员 vs Claude API

**会员方案**：
- 月费：¥140（$20）
- 额度：每 5 小时约 50 条消息（Claude 3.5 Sonnet）
- 按 30 天计算：约 7,200 条消息
- **单条成本**：¥0.019/条

**API 方案**（通过中转站）：
- Claude 3.5 Sonnet：约 ¥0.15/千 Token
- 单次对话（100 Token 输入 + 300 Token 输出）：约 ¥0.06
- ¥140 可用：约 2,333 次对话
- **单条成本**：¥0.06/条

**结论**：
- Claude Pro 的性价比优势更明显（单条成本仅为 API 的 1/3）
- 如果只需要聊天，优先选会员
- 如果需要集成到工作流、批量处理，才考虑 API

## 中转站会员又是什么？

### 定义
部分中转平台推出的**套餐制产品**，如"月卡 ¥29.9 包 200 万 Token"或"会员免费用 GPT-3.5"。

### 与官方会员的区别

| 项目 | 官方会员 | 中转站会员 |
|------|---------|----------|
| **提供方** | OpenAI、Anthropic 等 | 第三方中转平台 |
| **使用入口** | 官方网站或 App | 第三方客户端或网页 |
| **模型范围** | 仅自家模型 | 通常包含多家模型 |
| **额度规则** | 官方统一标准 | 平台自定义（需仔细阅读） |
| **到期处理** | 会员失效，历史记录保留 | 可能清空剩余额度或转为按量计费 |

### 购买前必须确认的 5 个问题

1. **包含哪些模型？**
   - 是否包含 GPT-4、Claude 3.5 等高级模型
   - 还是只有 GPT-3.5、Claude Haiku 等低成本模型

2. **有没有每日限制？**
   - "200 万 Token"是否可以一天用完
   - 是否有"每日 5 万 Token"的隐藏限制

3. **超出后如何收费？**
   - 套餐用完后是否自动按量扣费
   - 超量价格是多少（可能高于普通充值）

4. **到期余额清零吗？**
   - 会员到期后，剩余 Token 是否保留
   - 还是必须在 30 天内用完

5. **能否退款或转换？**
   - 不满意能否退款
   - 能否转为按量计费账户

## 怎样避免重复购买

### 先确定使用场景

| 场景 | 推荐方案 | 原因 |
|------|---------|------|
| 只在官网聊天，偶尔问问题 | 官方会员 | 固定月费，不用担心用量 |
| 需要在 VS Code、Cursor 中用 | API | 这些工具只支持 API |
| 要批量处理文档、自动化任务 | API | 会员有速率限制，API 更灵活 |
| 每天聊天超过 50 次 | 官方会员 | 性价比更高 |
| 偶尔用，每周几次 | API 小额充值 | 按需付费，不浪费 |
| 想同时用多个模型（GPT/Claude/Gemini） | 中转站 API | 一个账户调用多家模型 |

### 测试流程

**第 1 周**：小额充值 API（¥10-20），记录实际用量
**第 2 周**：根据账单计算：
- 如果每天花费 < ¥5，继续用 API
- 如果每天花费 > ¥5，考虑购买会员

**第 3 周**：如果买了会员，停止 API 充值，避免重复花钱

## 已有会员能否获得 API Key？

### 不能自动转换

**会员 ≠ API 权限**。即使你是 ChatGPT Plus 或 Claude Pro 会员，仍需：

1. 访问开发者平台（如 `platform.openai.com`）
2. 单独创建 API 账户
3. 绑定支付方式（通常需要信用卡）
4. 充值 API 余额

### 判断方法

登录开发者控制台后，如果看到：
- ✅ "API Keys"页面
- ✅ "Usage"账单明细
- ✅ "Billing"余额显示

说明你的账户已开通 API 权限。如果只看到会员订阅信息，说明还未开通 API。

### 特殊情况

- **OpenAI**：会员和 API 是完全独立的两个账户系统，互不影响
- **Anthropic**：Claude Pro 会员和 Claude API 使用同一个账户，但计费独立
- **中转站**：部分平台的"会员"实际上是预付费 API 套餐，需仔细阅读说明

## 常见误区

### 误区 1："买了 Plus 就能在 VS Code 里用 GPT-4"
❌ **错误**：VS Code 的 AI 插件需要 API Key，Plus 会员不提供。

✅ **正确**：需要单独在 `platform.openai.com` 充值 API 余额并创建密钥。

### 误区 2："API 比会员贵"
❌ **错误**：取决于使用频率。低频用户用 API 更便宜。

✅ **正确**：每天聊天超过 50 次，会员划算；少于 20 次，API 划算。

### 误区 3："中转站会员等于官方会员"
❌ **错误**：中转站会员是第三方套餐，规则完全不同。

✅ **正确**：购买前必须确认模型范围、限制规则、到期处理。

### 误区 4："充了 API 就不能用官网聊天了"
❌ **错误**：API 和会员互不影响。

✅ **正确**：可以同时拥有会员和 API，分别计费。

## 付款前的三个关键词

为了避免买错，付款时注意这三个词：

1. **订阅（Subscription）** → 会员，按月扣费
2. **API 余额（API Credits）** → 开发者接口，按用量扣费
3. **Token 套餐（Token Package）** → 中转站套餐，需确认规则

**检查清单**：
- [ ] 我知道这是会员还是 API
- [ ] 我确认了使用场景（聊天 or 集成）
- [ ] 我看过价格对比，选了更划算的方案
- [ ] 如果是中转站，我确认了套餐限制和到期规则
