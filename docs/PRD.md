# 产品需求文档 (PRD)

## 项目概述

**项目名称**: AIO Guide (AI API 服务商评测与对比平台)

**目标用户**: 需要使用 AI API 的中文用户，包括开发者、企业和个人

**核心价值**: 
- 提供中文 AI API 服务商的价格对比
- 人工核验的可靠数据
- 实用的接入教程
- 帮助用户做出明智的选择

## 功能范围

### 第一版包含的功能

#### 前台（公开访问）
1. **首页**
   - 平台介绍
   - 热门服务商推荐
   - 最新价格动态
   - 快速搜索入口

2. **服务商列表页**
   - 所有已发布的服务商
   - 筛选：支持的模型、价格区间、特色功能
   - 排序：价格、更新时间、推荐度
   - 分页展示

3. **服务商详情页**
   - 基本信息（名称、官网、简介）
   - 支持的模型和价格
   - 最后核验时间
   - 相关教程文章

4. **模型对比页**
   - 同一模型在不同服务商的价格对比
   - 价格趋势图表
   - 最优价格提示

5. **教程文章列表和详情**
   - 如何注册、充值、使用 API
   - 常见问题解答
   - 最佳实践分享

6. **价格历史**
   - 某个服务商的价格变化记录
   - 某个模型的市场价格走势

#### 后台（仅管理员）
1. **服务商管理**
   - 新增、编辑服务商信息
   - 上架/下架操作
   - 草稿保存

2. **模型管理**
   - 新增、编辑模型信息
   - 关联服务商

3. **渠道管理**
   - 管理每个服务商的不同渠道（如官方、代理）
   - 设置渠道优先级

4. **价格管理**
   - 单条价格编辑
   - 批量价格更新
   - CSV 导入/导出
   - 价格历史记录

5. **人工核验**
   - 标记核验时间
   - 过期数据提醒（超过 30 天未核验）

6. **教程管理**
   - 富文本编辑器
   - 草稿/发布状态
   - 文章分类

7. **数据导出**
   - 导出服务商列表
   - 导出价格数据
   - 导出点击统计

8. **操作日志**
   - 记录所有管理员操作
   - 可按时间、操作类型筛选

### 第一版不包含的功能
- 用户注册和登录（除管理员外）
- 自动价格抓取
- 定时可用性探测
- 自动化性能测试
- 用户评论和评分
- 用户收藏和对比
- API 接口对外开放
- 邮件通知
- 多语言版本

## 用户场景

### 场景 1: 用户寻找最便宜的 Claude API
1. 用户访问首页
2. 在搜索框输入 "Claude"
3. 查看所有提供 Claude API 的服务商
4. 按价格排序
5. 点击感兴趣的服务商查看详情
6. 阅读相关接入教程

### 场景 2: 管理员更新价格
1. 管理员登录后台
2. 进入价格管理页面
3. 筛选需要更新的服务商
4. 批量编辑价格
5. 标记核验时间
6. 发布更新

### 场景 3: 用户对比多个服务商
1. 用户访问模型对比页
2. 选择 "GPT-4" 模型
3. 查看价格对比表格
4. 查看价格历史趋势
5. 点击外链访问服务商官网

## 数据说明

### 服务商 (Provider)
- 名称
- 官网链接
- Logo URL
- 简介
- 是否推荐
- 发布状态
- 创建时间
- 更新时间

### 模型 (Model)
- 模型名称（如 gpt-4, claude-3-opus）
- 模型家族（如 GPT-4, Claude 3）
- 官方定价参考
- 简介

### 渠道 (Channel)
- 所属服务商
- 渠道名称（如官方、代理 A）
- 优先级
- 是否启用

### 价格 (Price)
- 所属渠道
- 所属模型
- 输入价格（元/百万 token）
- 输出价格（元/百万 token）
- 生效日期
- 是否当前价格
- 核验时间
- 备注

### 价格历史 (PriceHistory)
- 自动记录每次价格变更

### 教程文章 (Article)
- 标题
- 内容（Markdown）
- 关联服务商
- 发布状态
- 创建/更新时间

### 外链点击 (ClickEvent)
- 用户点击的服务商
- 点击时间
- 来源页面

### 操作日志 (AuditLog)
- 操作人
- 操作类型
- 操作对象
- 操作时间
- 详细内容

## 设计原则

1. **数据准确第一**: 所有数据由管理员人工核验，不自动抓取
2. **简单易用**: 用户无需注册即可查看所有公开信息
3. **透明度**: 明确显示最后核验时间，让用户知道数据新鲜度
4. **移动友好**: 响应式设计，手机也能方便使用
5. **SEO 优化**: 搜索引擎能正确索引内容

## 成功指标

### 第一版上线标准
- [ ] 至少收录 10 家服务商
- [ ] 至少 20 个模型的价格数据
- [ ] 至少 5 篇教程文章
- [ ] 后台管理功能完整可用
- [ ] 移动端和桌面端显示正常
- [ ] Lighthouse 性能分数 > 80
- [ ] 所有核心页面已正确设置 SEO meta

### 后续运营指标（上线后关注）
- 每日访问量
- 服务商详情页点击率
- 外链点击转化率
- 用户停留时长
- 搜索引擎流量占比

## 项目限制

1. **技术栈固定**: 不得更改 Next.js、TypeScript、Supabase、Vercel 的技术选型
2. **数据真实**: 禁止伪造数据、测试结果或虚假的核验记录
3. **版权合规**: 不得复制 Help AIO、API Ranking 等网站的设计、文案、图片、数据
4. **安全第一**: 必须遵循所有安全要求，不得将密钥写入代码
