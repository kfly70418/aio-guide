## 先用一句话理解 API

API 可以理解为软件之间沟通的窗口。你平时打开聊天网页，自己输入问题、点击发送；使用 API 时，则由另一个软件替你发送问题，再把模型的回答接回来。这个软件可以是聊天客户端、翻译工具、写作助手，也可以是公司内部系统。

大模型 API 通常包含四个角色：你的应用、API 服务地址、具体模型和身份凭证。应用把文字发送到服务地址，并说明要调用哪个模型；服务端验证身份凭证后处理请求，再返回文本或其他结果。

## 四个必须认识的词

1. **API Key**：类似专用钥匙，用来识别账户并计算用量，不能公开。
2. **Base URL**：请求发送到哪里，也常被叫作接口地址或 API 地址。
3. **模型名称**：告诉服务端使用哪个模型，必须按服务商提供的名称填写。
4. **Token**：模型计算文字用量的单位，不等于汉字数，也不等于聊天次数。

只要其中一项填错，就可能出现无法连接、无权限或找不到模型等提示。

## API 和聊天会员有什么区别

聊天会员通常按月付费，在官方网页或 App 内使用；API 通常按实际用量计费，供其他软件调用。购买聊天会员一般不会自动获得等额 API 额度，充值 API 余额也通常不能直接抵扣会员费。两者属于不同产品，付款前要看清页面名称。

## 新手什么时候需要 API

如果只是偶尔聊天，直接使用成熟的网页或 App 更省事。如果想在 Chatbox、Cherry Studio 等客户端中集中管理多个模型，或想让翻译、写作、编程工具自动调用模型，就需要 API。

## 第一次使用的正确顺序

先选择服务商并完成注册，再创建 API Key；随后在客户端填写接口地址、Key 和模型名称；最后用一个很短的问题测试。测试成功后再充值更多或导入长文档。这样即使配置有误，排查成本也很低。

> 记住：API 不是一个单独的软件，而是一种让软件调用 AI 能力的方式。先把地址、钥匙和模型名称对应好，就已经理解了大半。
