## 中转站在中间做了什么

AI API 中转站位于用户应用和模型提供方之间。你的客户端先把请求发送给中转站，中转站完成鉴权、计费和格式转换后，再向上游模型发起请求，最后把结果返回给你。

因此，中转站并不是模型本身。它提供的是接入、充值、线路和管理服务。同一个中转站可能同时提供多个模型，也可能为同一模型准备不同线路。

## 为什么有人选择中转站

常见原因包括付款方式更方便、一个账户可使用多家模型、接口格式比较统一，以及国内网络环境下连接更容易。对于只想在客户端中使用模型的新手，统一余额和统一设置也能减少学习成本。

## 需要正视的风险

中转站理论上能够接触到经过它转发的请求内容，因此不应发送密码、身份证、未公开合同、客户资料或公司机密。小型平台还可能出现线路波动、余额规则变化、停止运营或售后响应慢等问题。

价格特别低也不一定代表更划算。可能存在模型名称与实际模型不一致、上下文被缩短、响应质量不稳定，或者低价只适用于特定线路的情况。

## 什么人更适合使用

希望体验多个模型、单次用量不大、能够自行判断内容敏感程度的个人用户，可以从小额试用开始。处理商业机密、医疗信息、源代码仓库或客户数据的团队，应优先考虑官方 API、企业协议或经过安全审查的供应商。

## 一个稳妥的使用原则

先查看运营时间、计费说明、退款规则、联系方式和近期维护记录，再用很小的金额测试。测试时关注能否稳定返回、模型是否正确、账单能否核对以及客服是否可联系。不要因为首充优惠一次存入长期预算。

> 中转站解决的是接入便利问题，不会自动消除隐私、稳定性和预付费风险。把它当作一项需要评估的网络服务，而不是只看价格的充值卡。
