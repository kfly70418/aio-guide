# 俄语排版标准分析

## 1. 俄语排版的特殊要求

### 标点符号
- **引号**: 俄语使用 «双尖引号» 或 „底引号"，而不是英文的 "双引号"
- **破折号**: 俄语使用长破折号（—）代替连字符，前后需要空格
- **省略号**: 使用 … 而不是 ...

### 字体和间距
- **行高**: 俄语文本建议使用 1.5-1.8 的行高（比英文略高）
- **字间距**: 西里尔字母比拉丁字母稍宽，需要适当调整
- **段落间距**: 段落之间需要明显的间距（1.5-2em）

### 对齐方式
- **正文**: 两端对齐（justified）在俄语排版中很常见
- **标题**: 左对齐
- **列表**: 使用悬挂缩进

### 数字和单位
- **日期格式**: DD.MM.YYYY（如 16.08.2026）
- **数字分隔符**: 使用空格而不是逗号（如 10 000 而不是 10,000）
- **货币**: ₽ 符号放在数字后面（100₽）

## 2. 当前实现的问题

### ✅ 已正确实现
- 使用 Cyrillic 字体子集
- 段落有足够的行高（prose-p:leading-relaxed）
- 标题加粗显示

### ⚠️ 可能需要改进
1. **行高**: 当前使用 `leading-relaxed` (1.625)，俄语建议 1.7-1.8
2. **引号**: Markdown 内容中可能包含英文引号，应转换为俄语引号
3. **破折号**: 需要确保使用长破折号（—）
4. **段落间距**: 可能需要增加
5. **对齐方式**: 俄语正文通常使用两端对齐

## 3. 建议的改进

### CSS 调整
```css
/* 俄语特定的排版样式 */
[lang="ru-RU"] .prose {
  line-height: 1.75;  /* 增加行高 */
  text-align: justify;  /* 两端对齐 */
  hyphens: auto;  /* 自动断字 */
}

[lang="ru-RU"] .prose p {
  margin-bottom: 1.5em;  /* 增加段落间距 */
}

[lang="ru-RU"] .prose h2,
[lang="ru-RU"] .prose h3 {
  margin-top: 2em;  /* 标题上方留更多空间 */
  margin-bottom: 1em;
}

[lang="ru-RU"] .prose ul,
[lang="ru-RU"] .prose ol {
  padding-left: 2em;  /* 列表缩进 */
}
```

### 内容转换
- 将英文引号 "..." 转换为俄语引号 «...»
- 确保破折号格式正确
- 数字格式本地化
