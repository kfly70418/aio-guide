После настройки Base URL, API Key и модели сначала протестируйте перед использованием. Метод тестирования прост: отправьте AI сообщение "привет" и проверьте, получите ли нормальный ответ.

В этой статье представлены 3 метода тестирования, выберите наиболее подходящий для вас.

## Метод 1: Тестирование онлайн-инструментом (самый простой)

Не требует установки программ, просто откройте веб-страницу.

### Тестирование с помощью Hoppscotch

**Адрес**: https://hoppscotch.io/

**Шаги**:

1. Откройте сайт, выберите **POST** запрос
2. Заполните адрес:
   ```
   https://домен-вашего-агрегатора/v1/chat/completions
   ```
   Например: `https://api.openai-hk.com/v1/chat/completions`

3. Нажмите вкладку **Headers**, добавьте 2 строки:
   - `Content-Type` заполните `application/json`
   - `Authorization` заполните `Bearer ваш-API-ключ` (с пробелом после Bearer)

4. Нажмите вкладку **Body**, выберите **Raw**, вставьте тестовый код:
   ```json
   {
     "model": "gpt-4o-mini",
     "messages": [{"role": "user", "content": "привет"}],
     "max_tokens": 20
   }
   ```

5. Нажмите **Send** для отправки

**Успешный результат**:

Возвращается JSON с полем `"content"`, содержащим ответ AI:

```json
{
  "choices": [
    {
      "message": {
        "content": "Привет! Чем могу помочь?"
      }
    }
  ],
  "usage": {
    "total_tokens": 18
  }
}
```

Если видите это — конфигурация правильная.

**Неудачный результат**:

| Сообщение об ошибке | Причина | Как исправить |
|---------|------|--------|
| 401 Unauthorized | Неверный API Key | Скопируйте ключ заново, убедитесь в отсутствии лишних пробелов |
| 404 Not Found | Неправильный адрес | Проверьте домен и `/v1/chat/completions` |
| Invalid model | Неверное имя модели | Попробуйте `gpt-4o-mini` |

## Метод 2: Тестирование клиентом (рекомендуется)

Если у вас установлен Chatbox или Cherry Studio, тестируйте прямо в программе.

### Тестирование с Chatbox

1. Откройте Chatbox, нажмите **иконку шестеренки** в правом верхнем углу (настройки)
2. Слева выберите **AI Providers**
3. Нажмите **+** для добавления пользовательского провайдера
4. Заполните конфигурацию:
   - **Имя**: любое, например "Тест"
   - **API Domain**: `https://домен-вашего-агрегатора/v1`
   - **API Key**: вставьте ваш ключ
   - **Model**: выберите `gpt-4o-mini`

5. Нажмите **Сохранить**

6. Закройте настройки, в диалоговом окне введите "привет" и отправьте

**Успех**: через несколько секунд получен ответ AI
**Неудача**: отображается сообщение об ошибке, проверьте конфигурацию согласно подсказке

---

### Тестирование с Cherry Studio

Cherry Studio имеет функцию проверки в один клик:

1. Добавьте конфигурацию провайдера (шаги аналогичны Chatbox)
2. Нажмите кнопку **Verify**
3. Автоматическое тестирование и отображение результата

При успехе отображается зеленая ✓, при неудаче — конкретная ошибка.

## Метод 3: Тестирование командной строкой (для разработчиков)

Подходит для пользователей командной строки.

**Windows (PowerShell)**:

```powershell
curl -X POST "https://ваш-домен/v1/chat/completions" `
  -H "Content-Type: application/json" `
  -H "Authorization: Bearer ваш-ключ" `
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"привет"}],"max_tokens":20}'
```

**macOS/Linux**:

```bash
curl -X POST "https://ваш-домен/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer ваш-ключ" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"привет"}],"max_tokens":20}'
```

Возврат JSON означает успех, возврат сообщения об ошибке означает неудачу.

## Контрольный список тестирования

При тестировании подтвердите следующее:

- [ ] Формат Base URL: `https://домен/v1` (обратите внимание на `https://` и `/v1`)
- [ ] Полный API Key: скопируйте всё от начала `sk-` до конца
- [ ] Имя модели: `gpt-4o-mini` (обратите внимание на дефисы `-`)
- [ ] Нормальный ответ: отправка "привет" получает ответ
- [ ] Подсчет токенов: в ответе есть поле `usage`

## Часто задаваемые вопросы

**Q: Тест успешен, но не работает на практике?**

Возможно, формат Base URL в клиенте отличается. Некоторым клиентам нужно убрать `/v1` и заполнить отдельно в другом месте. Проверьте документацию клиента.

**Q: Отображается "модель не существует"?**

1. Проверьте написание: `gpt-4o-mini` нельзя писать как `gpt4o-mini`
2. Проверьте на сайте провайдера, какие модели поддерживаются
3. Попробуйте самую базовую модель

**Q: Тест успешен, но списание неправильное?**

Запишите количество токенов при тестировании (`total_tokens`), сравните со счетом. Если цена за единицу явно выше официальной, обратитесь в поддержку или смените провайдера.

Справка: [Как сравнивать цены AI API?](/ru/articles/compare-ai-api-real-cost)

## Объяснение стоимости

Тестирование потребляет небольшое количество токенов, стоимость очень низкая:

- Тестирование с `gpt-4o-mini`
- Установка `max_tokens: 20`
- Один тест примерно 0.0001-0.0005 юаня
- 10 тестов меньше 1 копейки

## Напоминание о безопасности

- Не вводите API Key в онлайн-инструменты на общедоступных компьютерах
- Своевременно закрывайте вкладки браузера после тестирования
- Не делитесь API Key с другими
- Используйте полный ключ для теста, не угадывайте по части

Справка: [Руководство по безопасности API Key](/ru/articles/api-key-security-basics)

## Что делать после успешного теста

1. Сохраните конфигурацию: запишите успешные Base URL и имя модели
2. Установите бюджет: избегайте перерасхода, см. [Управление API ключами и бюджетом](/ru/articles/manage-api-keys-and-budget)
3. Подготовьте резерв: на случай сбоя провайдера, см. [Как подготовить резервные каналы API](/ru/articles/build-multi-provider-backup)
