## Введение

При первой регистрации в сервисе AI API 90% новичков сталкиваются с проблемами: пополнение не на ту платформу (фишинговый сайт), переплата без возможности возврата, ошибки настройки и невозможность использования. Правильный процесс состоит из 4 этапов: проверка официального сайта перед регистрацией (избежание фишинга), небольшое тестирование перед пополнением (проверка работоспособности), создание ключей с настройкой прав (защита безопасности), сверка счетов после тестирования (подтверждение правильности). Эта статья дает 32 пункта контрольного списка и конкретные операции для каждого шага, помогая избежать распространенных ловушек, проверено в августе 2026 года.

## Подготовка

Перед регистрацией вам нужно:

1. **Определите потребности**  
   - Сценарий использования: чат / перевод / программирование
   - Бюджет: ¥50 / ¥200 / ¥500 в месяц
   - Модель: GPT-4 / Claude / Gemini

2. **Подготовьте материалы**  
   - Email (рекомендуется выделенный)
   - Способ оплаты (Alipay/WeChat/кредитная карта)
   - Менеджер паролей (например, Bitwarden)

3. **Ожидаемое время**  
   Полный процесс около 30-45 минут

## Этап 1: Проверка перед регистрацией (10 пунктов)

### ✅ 1. Подтвердите доступ к настоящему официальному сайту

**Как проверить**:

| Проверка | Правильно | Неправильно |
|--------|------|------|
| Домен | `openai.com` | `openai-api.com` ❌ |
| HTTPS | ✅ Есть зеленый замок | ❌ Предупреждение о небезопасности |
| Поисковик | Первый органический результат | Рекламное место (помечено "Реклама") |

**Распространенные фишинговые методы**:

| Настоящий сайт | Фишинговый сайт |
|---------|---------|
| `openai.com` | `openai-api.com` |
| `anthropic.com` | `anthropic-ai.com` |
| `claude.ai` | `claude-api.com` |

**Метод проверки 1: Просмотр домена**

```
✅ Правильно: https://platform.openai.com/signup
❌ Фишинг: https://openai-platform.com/signup
```

**Метод проверки 2: Просмотр сертификата**

1. Нажмите на значок замка в адресной строке браузера
2. Просмотрите информацию о сертификате
3. Подтвердите, что выдан для правильного домена, например `openai.com`

**Реальный случай** (2025-11):
- Пользователь искал "OpenAI API регистрация"
- Кликнул на первый результат (реклама)
- Домен был `openai-register.com`
- Пополнил ¥500, затем обнаружил, что это фишинговый сайт
- Потерял всю сумму, невозможно вернуть

### ✅ 13. Разберитесь с пополненным vs подарочным балансом

**Сравнение типов баланса**:

| Тип | Описание | Можно ли вернуть |
|------|------|---------|
| Пополненный баланс | Сумма, которую вы фактически заплатили | Некоторые платформы могут |
| Подарочный баланс | Подарок от акции (например, пополни 100 получи 20) | Обычно нельзя |
| Пробный баланс | Подарок при регистрации | Нельзя |

**Типичные условия**:

```
Пополнение ¥100, подарок ¥20, всего ¥120

Пояснение:
- Пополненный баланс (¥100) можно запросить возврат
- Подарочный баланс (¥20) невозвратный
- Приоритетно используется подарочный баланс
```

**Предупреждение**:
- Если пополнение ¥1000 дает ¥500, при исчезновении платформы вы теряете ¥1000
- Не поддавайтесь соблазну крупных подарков

```

### ✅ 28. Отправьте короткий тестовый запрос

**Первое тестовое сообщение**:

```
Вы: Пожалуйста, ответьте только: Подключение успешно

Ожидаемый ответ: Подключение успешно
```

**Почему короткое сообщение**:
- Мало токенов, низкая стоимость (около ¥0.001)
- Быстро проверяет правильность настройки
- При неудаче легко диагностировать

**Признаки успеха**:
- ✅ Ответ получен за 1-3 секунды
- ✅ Содержание ответа правильное
- ✅ Нет сообщений об ошибках

**При неудаче**:
- 401 → Неверный API Key, скопируйте заново
- 404 → Неверный Base URL, проверьте наличие /v1
- model not found → Неверное название модели, выберите из списка моделей

### ✅ 29. Проверьте записи счетов

**Войдите в консоль и просмотрите счет**:

| Проверка | Ожидаемое значение |
|--------|--------|
| Время | Время только что отправленного сообщения |
| Модель | gpt-4-turbo-2024-04-09 |
| Токены ввода | Около 10 |
| Токены вывода | Около 5 |
| Стоимость | Около ¥0.001-0.002 |

**Предупреждающие сигналы**:

| Явление | Возможная проблема |
|------|---------|
| Нет записей в счете | Возможно бесплатное пробное использование или задержка записи |
| Аномально много токенов | Возможно включен системный промпт |
| Аномально высокая стоимость | Слишком высокий множитель цены, проверьте прайс-лист |

### ✅ 30. Тестирование китайского вывода

**Второе тестовое сообщение**:

```
Вы: Расскажите о Пекине в 100 словах

Ожидание: Возврат описания на китайском языке около 100 слов

**Проверка**:
- Китайский вывод нормальный (без кракозябр)
- Количество слов соответствует требованиям
- Содержание точное

### ✅ 31. Тестирование контекста

**Третье, четвертое тестовые сообщения**:

```
Вы: Какая столица Китая?
AI: Пекин.

Вы: Какое там население?
AI: Население Пекина около 21.54 миллиона (по состоянию на 2023 год).
```

**Проверка**:
- Во втором раунде понимает ли "там" как Пекин
- Означает, что функция контекста работает нормально

### ✅ 32. Тестирование остановки генерации

**Операция**:
1. Отправьте: "Подробно расскажите о Пекине в 1000 словах"
2. Подождите 2 секунды
3. Нажмите кнопку "Остановить генерацию"

**Проверка**:
- Можно ли немедленно остановить
- Учитывается ли в счете только уже сгенерированная часть

## Частые ошибки

### Ошибка 1: Импульсивное крупное пополнение

**Случай**:
- Увидели "пополни 1000 получи 500"
- Пополнили ¥1000 без тестирования
- Обнаружили плохое качество сервиса
- Невозможность возврата

**Правильные действия**:
- Сначала пополните ¥10-20 для теста
- Используйте 1-2 недели для подтверждения стабильности
- Затем пополняйте по месячному бюджету

### Ошибка 2: Не сохранили API Key

**Случай**:
- После создания ключа не сохранили
- После закрытия страницы невозможно снова просмотреть
- Можно только создать заново

**Правильные действия**:
- Сразу после создания скопируйте
- Вставьте в менеджер паролей
- Закрывайте страницу только после подтверждения сохранения

### Ошибка 3: Не установили ограничения прав

**Случай**:
- Права ключа установлены как "Все модели"
- После утечки ключа произошла кража средств
- За 1 день израсходовано ¥3000

**Правильные действия**:
- Открывайте только нужные модели
- Устанавливайте дневной лимит ¥20-50
- Регулярно проверяйте счета

### Ошибка 4: Не тестируя, сразу массово используете

**Случай**:
- После пополнения сразу загружаете 100 файлов для массовой обработки
- Обнаруживаете, что модель неправильная (подмена)
- Уже израсходовано ¥500, невозможность возврата

**Правильные действия**:
- Сначала отправьте несколько коротких сообщений для теста
- Проверьте подлинность модели
- Массовая обработка только после проверки счета

### Ошибка 5: Забыли подготовить резерв

**Случай**:
- Настроен только один провайдер
- Сбой провайдера, работа полностью прервана
- Срочная регистрация нового аккаунта заняла 2 часа

**Правильные действия**:
- Подготовьте минимум 2 независимых провайдеров
- Резервный аккаунт уже пополнен на ¥10
- Тестируйте раз в месяц для подтверждения работоспособности
