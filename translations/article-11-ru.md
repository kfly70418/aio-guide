## Введение: 10 минут до первого диалога, без кода

Не умея программировать, вы можете использовать AI API. Подготовьте три вещи: адрес интерфейса от провайдера (Base URL), ключ (API Key), название модели (например, gpt-4). Выберите клиент с поддержкой "пользовательского провайдера", введите эти три элемента и начните диалог.

**Реальная стоимость**: Первый тест потребляет около 0.02-0.05 юаня (на основе OpenOx с минимальным пополнением 1 юань, тест 2026-08-14). Весь процесс не требует установки инструментов разработки или написания кода.

Эта статья основана на реальном процессе настройки двух популярных клиентов Chatbox и Cherry Studio, проводя вас через все шаги от нуля до первого диалога.

---

## Подготовка

### Три необходимые вещи

1. **Аккаунт провайдера AI API**
   - Рекомендация для новичков: OpenOx (пополнение от 1 юаня, бонус $3 для тестирования)
   - Или: UU API (пополнение от 1 юаня, бонус при вступлении в группу)
   - После регистрации получите: Base URL, API Key

2. **Клиент с поддержкой пользовательского провайдера** (выберите один)
   - **Chatbox**: https://chatboxai.app/
   - **Cherry Studio**: https://cherry-ai.com/
   - Оба поддерживают Windows/Mac/Linux, простой интерфейс, подходит для новичков

3. **Небольшой тестовый бюджет**
   - Минимум 1 юань для начала тестирования
   - Первый диалог потребляет около 0.02-0.05 юаня
   - Рекомендуется пополнить 5-10 юаней, достаточно для 100-200 тестовых диалогов

### Ожидаемое время

- Регистрация аккаунта провайдера: 3-5 минут
- Загрузка и установка клиента: 2-3 минуты
- Настройка информации API: 3-5 минут
- Первый тестовый диалог: 1-2 минуты

**Итого**: 10-15 минут

### Напоминания о безопасности

⚠️ **При загрузке клиента**:
- Загружайте только с официального сайта или GitHub Releases
- Не используйте "модифицированные версии" из облачных хранилищ
- Клиент может читать ваши ключи и содержимое диалогов

⚠️ **При вводе ключа**:
- Не показывайте полный ключ на скриншотах
- Не делитесь ключом в групповых чатах
- Создавайте отдельный ключ для каждого клиента

## Детальные шаги

### Шаг 1: Получение информации API

**Операция**:
1. Войдите в ваш аккаунт провайдера API (в этой статье используется пример OpenOx)
2. Нажмите "Консоль" или "Dashboard" в правом верхнем углу страницы
3. Найдите "API Keys" или "Ключи API" в левом меню

**Заполнение**:
- Нажмите кнопку "Создать новый ключ"
- Название: `Тестовый клиент`
- Лимит квоты: установите 5 юаней (опционально, для предотвращения злоупотребления)
- Нажмите "Подтвердить создание"

**Проверка**:
После успешного создания вы увидите три ключевых элемента информации:

```
Base URL: https://api.openox.tech/v1
API Key: sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Доступные модели: gpt-4, gpt-3.5-turbo, claude-3-sonnet...
```

**Результат**:
- ✅ Скопируйте Base URL в блокнот
- ✅ Скопируйте API Key в блокнот (отображается только один раз, после закрытия больше не увидите)
- ✅ Скопируйте название модели (например, `gpt-4`)

> ⚠️ **Внимание**: API Key обычно начинается с `sk-`, полная длина около 48-51 символов. Если при копировании случайно добавили пробел или перевод строки, позже получите ошибку 401.

---

### Шаг 2: Загрузка и установка клиента

**Операция** (на примере Chatbox):
1. Посетите https://chatboxai.app/
2. Нажмите кнопку "Download" в центре страницы
3. Выберите вашу операционную систему (Windows/Mac/Linux)

**Заполнение**:
- Windows: Загрузите установочный пакет `.exe`
- Mac: Загрузите файл `.dmg`
- Linux: Загрузите файл `.AppImage`

**Проверка**:
- Windows: Дважды кликните на установочный пакет, следуйте инструкциям
- Mac: Перетащите в папку Applications
- Linux: Дайте права на выполнение и запустите напрямую

**Результат**:
Откройте Chatbox, при первом запуске увидите приветственный экран с подсказкой "Выберите провайдера AI".

---

### Шаг 3: Настройка пользовательского провайдера

**Операция**:
1. Нажмите на значок "Настройки" (шестеренка) в левом нижнем углу Chatbox
2. На странице настроек найдите "AI Provider" или "Провайдер AI"
3. Нажмите "Добавить пользовательского провайдера" или "Add Custom Provider"

**Заполнение** (последовательно заполните каждый пункт):

**① Название провайдера**:
```
OpenOx (или название вашего провайдера)
```

**② API протокол**:
- Выберите из выпадающего списка: `OpenAI Compatible` (Совместимо с OpenAI)
- Большинство агрегаторов используют этот протокол

**③ Base URL**:
```
https://api.openox.tech/v1
```
⚠️ Внимание:
- Не удаляйте `/v1` в конце
- Не добавляйте лишний слэш, превращая в `/v1/`
- Подтвердите полноту заголовка протокола `https://`

**④ API Key**:
```
sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```
⚠️ Внимание:
- При вставке убедитесь, что нет пробелов в начале и конце
- Полная длина около 48-51 символов
- Если скопировали не полностью, получите ошибку 401

**⑤ Список моделей**:
- Нажмите "Добавить модель"
- Введите ID модели: `gpt-4`
- Опционально: продолжите добавлять `gpt-3.5-turbo`, `claude-3-sonnet` и др.

**Проверка**:
После заполнения страница должна показывать:
- ✅ Зеленая галочка рядом с названием провайдера
- ✅ Список моделей отображает добавленные вами модели
- ✅ Нет красных сообщений об ошибках

**Результат**:
Нажмите кнопку "Сохранить" или "Save" в правом нижнем углу страницы, конфигурация вступит в силу.

### Шаг 4: Первый тестовый диалог

**Операция**:
1. Вернитесь на главный экран Chatbox
2. Нажмите "Новый чат" или "New Chat" в левом верхнем углу
3. В селекторе моделей выберите только что настроенную `gpt-4`

**Заполнение**:
Введите следующий тестовый текст в диалоговое окно (рекомендуется скопировать):

```
Пожалуйста, ответьте только четырьмя словами: подключение успешно
```

**Почему использовать этот тест**:
- ✅ Короткий запрос, быстрый ответ (обычно 1-2 секунды)
- ✅ Низкая стоимость (около 0.01 юаня)
- ✅ Ясный результат, легко определить успех

**Проверка**:
В нормальной ситуации AI ответит:

```
Подключение успешно
```

Или похожие четыре слова (например, "Соединение нормальное").

**Результат**:
✅ **Если получен ответ**:
- Означает успешную настройку
- Можно переходить к следующему полному тесту

❌ **Если ошибка**:
- Перейдите к разделу "Частые ошибки" ниже для диагностики

---

### Шаг 5: Полный функциональный тест

**Операция**:
В том же диалоге отправьте следующий длинный текст для теста:

```
Пожалуйста, резюмируйте три ключевых момента следующего текста:

Технология искусственного интеллекта быстро развивается, возможности больших языковых моделей постоянно расширяются.
От генерации текста до понимания изображений, AI уже может обрабатывать различные типы задач.
Однако, как сделать эти мощные модели доступными для большего числа пользователей, как снизить порог использования,
все еще остаются важными проблемами, требующими решения. Появление API-сервисов
позволяет обычным пользователям удобно использовать эти передовые возможности AI.
```

**Проверка**:
AI должен вернуть резюме, похожее на это:

```
1. Технологии AI и возможности больших языковых моделей быстро растут
2. AI может обрабатывать различные типы задач (текст, изображения и т.д.)
3. API-сервисы снизили порог использования AI
```

**Результат**:
✅ **Если нормально вернулось резюме**:
- Означает, что API полностью работоспособен
- Можно начать нормальное использование

✅ **Проверьте счет**:
1. Вернитесь в консоль провайдера
2. Найдите страницу "Статистика использования" или "Счета"
3. Подтвердите, что два только что проведенных диалога создали записи списания

Ожидаемое списание:
- Первый раз (короткий текст): около 0.01-0.02 юаня
- Второй раз (длинный текст): около 0.03-0.05 юаня
- Всего: около 0.04-0.07 юаня

## Частые ошибки

### Ошибка 1: 401 Unauthorized

**Сообщение об ошибке**:
```
Error: 401 Unauthorized
Invalid API Key
```

**Причина**:
- API Key скопирован не полностью (пробелы в начале/конце или недостает символов)
- API Key истек или был отозван
- API Key не активирован (некоторые провайдеры требуют пополнения перед использованием)

**Решение**:
1. Заново скопируйте API Key, подтвердите полноту
2. В бэкэнде провайдера подтвердите статус ключа (активен ли, не истек ли)
3. Если это только что созданный ключ, подождите 1-2 минуты и попробуйте снова
4. При необходимости удалите старый ключ и создайте новый

---

### Ошибка 2: 404 Not Found

**Сообщение об ошибке**:
```
Error: 404 Not Found
The requested URL was not found
```

**Причина**:
- Base URL заполнен неправильно (добавлен или упущен путь)
- Примеры распространенных ошибок:
  - ❌ `https://api.example.com` (отсутствует `/v1`)
  - ❌ `https://api.example.com/v1/` (лишний слэш в конце)
  - ❌ `https://api.example.com/v1/chat` (добавлен лишний `/chat`)

**Решение**:
1. Проверьте стандартный формат Base URL в документации провайдера
2. Большинство должно быть: `https://домен/v1`
3. Удалите лишние пути или слэши
4. Подтвердите, что заголовок протокола `https://`, а не `http://`

---

### Ошибка 3: Модель не существует

**Сообщение об ошибке**:
```
Error: Model not found
The model 'gpt-4' does not exist
```

**Причина**:
- Ошибка в написании названия модели (чувствительно к регистру)
- Провайдер не поддерживает эту модель
- Название модели требует префикс (например, `openai/gpt-4`)

**Решение**:
1. Проверьте список моделей в документации провайдера
2. Подтвердите точное написание названия модели:
   - ✅ `gpt-4`
   - ❌ `GPT-4` (ошибка в регистре)
   - ❌ `gpt4` (отсутствует дефис)
3. Скопируйте ID модели из бэкэнда провайдера, не вводите вручную
4. Попробуйте `gpt-3.5-turbo` для теста (почти все провайдеры поддерживают)

---

### Ошибка 4: Тайм-аут сети

**Сообщение об ошибке**:
```
Error: Request timeout
Failed to connect to API
```

**Причина**:
- Проблема локальной сети
- Нестабильный API-сервис провайдера
- Конфликт настроек прокси клиента

**Решение**:
1. Проверьте локальное сетевое соединение (можете ли получить доступ к другим сайтам)
2. Отключите VPN или прокси-программу и попробуйте снова
3. Переключитесь на мобильную точку доступа для теста (исключите проблему сетевой среды)
4. Если тайм-аут продолжается, свяжитесь с провайдером для подтверждения статуса сервиса
5. Попробуйте переключиться на резервного провайдера

## Объяснение стоимости

### Стоимость первого теста

На основе OpenOx (цены на 2026-08-14):
- **Минимальное пополнение**: 1 юань
- **Бонус новичку**: 3 доллара для тестирования
- **Расход первого теста**: 0.04-0.07 юаня (два диалога)

**Рекомендации по бюджету**:
- Только тест: пополните 5 юаней (около 100 диалогов)
- Повседневное использование: пополните 20 юаней (около 400-500 диалогов)
- Интенсивное использование: пополните 50-100 юаней

### Стоимость разных моделей

| Модель | Цена ввода | Цена вывода | Стоимость одного диалога |
|------|---------|---------|------------|
| gpt-3.5-turbo | $0.50/M tokens | $1.50/M tokens | 0.02-0.05 юаня |
| gpt-4 | $30/M tokens | $60/M tokens | 0.15-0.30 юаня |
| claude-3-sonnet | $3/M tokens | $15/M tokens | 0.05-0.10 юаня |

**Пояснение**:
- M tokens ≈ 750 китайских символов или 1000 английских слов
- Стоимость одного диалога предполагает ввод 100 символов, вывод 200 символов
- Фактическая стоимость зависит от счета в бэкэнде провайдера

### Политика возврата

Политика возврата разных провайдеров:
- **OpenOx**: Поддерживает возврат без комиссии (требуется ручная проверка)
- **UU API**: Не поддерживает возврат
- **APINebula**: Возврат в течение 7 дней (комиссия 5%)

**Рекомендация**:
- Первое пополнение не должно быть слишком большим (5-20 юаней достаточно)
- Пополняйте больше после удовлетворительного тестирования
- Выбирайте провайдеров с поддержкой возврата для снижения риска

## Напоминания о безопасности

### Защита ключей

❌ **Не делайте**:
- Не показывайте полный ключ на скриншотах
- Не делитесь ключом в групповых чатах или на форумах
- Не отправляйте ключ в публичные Git-репозитории
- Не используйте один ключ для нескольких пользователей

✅ **Следует делать**:
- Создавайте отдельный ключ для каждого клиента
- Устанавливайте лимит квоты для каждого ключа (например, 10 юаней)
- Регулярно (ежемесячно) меняйте ключи
- Своевременно отзывайте неиспользуемые ключи

### Безопасность содержимого диалогов

⚠️ **Не отправляйте в диалогах**:
- Номера ID, номера банковских карт, пароли
- Внутренние документы компании, коммерческие тайны
- Частную информацию других людей
- Полные API-ключи или токены доступа

### Переключение устройств

**Правильные действия при смене компьютера**:
1. На старом компьютере отзовите ключ этого устройства в бэкэнде провайдера
2. На новом компьютере создайте новый ключ
3. Не копируйте файлы конфигурации со старого компьютера напрямую на новый

Таким образом, даже если старый компьютер потерян, это не повлияет на использование других устройств.
